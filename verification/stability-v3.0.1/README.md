# UI Test Actions v3.0.1 stability and reliability

The independent consumer called `ui-test-actions/ui-test-actions@0c818c5d72e8c30c59bd1287c330a40392bf8e89` through `uses:`. Its workflows held parallel disposable GitHub runners. External observers used the published Python client and separate per-session bearers. [Action source](https://github.com/ui-test-actions/ui-test-actions/tree/0c818c5d72e8c30c59bd1287c330a40392bf8e89) · [Consumer workflow sources](../../.github/workflows/)

## Fixes and baseline failures

- v3.0.0 executed a repeated mutation after the reply fell out of its 64-entry cache. v3.0.1 keeps bounded request-ID fingerprints for the session and rejects evicted or unfinished replays before dispatch. The regression also checks a driver that applied a mutation before failing to serialize its result. At 65,536 accepted IDs, new IDs were rejected and 10,000 cached reuses completed with 64 bytes more traced allocations than the saturation checkpoint. This measures the local engine's Python allocations. [Capacity output](local/request-id-capacity.json)
- v3.0.0 applied both legacy and v2 input when the received bytes formed complete JSON and the declared HTTP body was longer. Both paths now require valid framing and the full byte count. Legacy input releases the worker immediately when the driver is occupied. A local saturation check showed a 25th reader was refused while 24 connections occupied workers, and the same session responded after slots were freed. [Worker saturation](local/worker-saturation.json)
- v3.0.0 could click after expiry when a native element refresh crossed the deadline. The action now checks the deadline after observation and again before a derived click. The Python client also preserves the request ID when an action response is incomplete, malformed, or tied to a different request. It reports an uncertain outcome before the caller chooses how to recover.
- The startup wrapper handles SIGTERM by writing the same stop marker used on interruption. The detached local test child observed that marker at the candidate pin. A repeated `recording.stop` returns consistent metadata and the encoder releases its raw frame buffers after the GIF is finalized. [Recording repeat and partial capture](local/recording-repeat.json) · [Startup interruption](local/interrupted-start.json)
- 109 local tests passed in each of eight consecutive runs. Hosted Windows, macOS, and Ubuntu passed the same 109 tests. Hosted Ubuntu also passed 11 mobile LAN tests and compiled the native frame-port source with warnings as errors. [Local repeats](local/repeats.json) · [Hosted regressions](https://github.com/ui-test-actions/ui-test-actions/actions/runs/44864317894)

## Reproduce and scope

Dispatch the independent desktop or mobile lifetime workflow with `purpose=v301-stress`, a fresh token digest, and the selected duration. Download the published connection and use the Action client at the same commit. Run the separate observer with the published checkout and its `verification` directory on `PYTHONPATH`. If iOS presents the native confirmation after the crash deep link, accept that dialog in the live Simulator and use `--case recovery` to observe the existing crash without sending another deep link. [Observer](../probe_hardening.py) · [Final-minute observer](https://github.com/ui-test-actions/ui-test-actions/blob/0c818c5d72e8c30c59bd1287c330a40392bf8e89/verification/probe_lifetime.py) · [Public connection instructions](https://github.com/ui-test-actions/ui-test-actions/tree/0c818c5d72e8c30c59bd1287c330a40392bf8e89#connect-and-hand-the-session-to-an-agent)

```bash
PYTHONPATH="$UI_ACTION_CHECKOUT:$UI_ACTION_CHECKOUT/verification" \
  python3 verification/probe_hardening.py connection.json \
    --token-file "$TOKEN_FILE" --output /tmp/ui-stability-proof
```

The mobile runs qualify Android API 35 and the chosen Apple Silicon Simulator and toolchain. Physical keyboard composition, physical radios, and other hosted images or optional backends require their own runs. The Named Tunnel and Service Auth v3.0.0 live proof remains available. The patch's regression suite exercises Named restart handling without requesting new account credentials. Quick Tunnel provider outages remain possible, and in-flight native actions can have an uncertain outcome after a lost connection.
